# Política de Privacidade

O aplicativo foi desenvolvido por Gustavo Nardi Nogueira como um aplicativo Gratuito. Este SERVIÇO é fornecido sem custos e destina-se ao uso "no estado em que se encontra".

## Coleta e Uso de Dados
O aplicativo não coleta, não armazena em servidores externos e não compartilha dados pessoais dos usuários. Todas as informações referentes à sua coleção de figurinhas são armazenadas exclusivamente de forma **local** no seu próprio dispositivo. 

## Uso do Microfone
O aplicativo solicita permissão de uso do microfone estritamente para o recurso de reconhecimento de voz local (ditar as figurinhas). Nenhum áudio é gravado, armazenado ou enviado para servidores de terceiros por parte do desenvolvedor.

## Segurança
Valorizamos a sua confiança em nos fornecer as permissões necessárias, mas lembramos que nenhum método de transmissão pela internet ou armazenamento eletrônico é 100% seguro.
